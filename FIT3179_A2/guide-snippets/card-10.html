Chart 10 / Export–import comparison

Almond earns a $1.3bn surplus; walnut, pistachio and hazelnut import more than they export

Reported export and import values in the handbook, 2025. All seven crops are included; a connector is drawn only where both values are reported.

Key takeaway

Exporting a crop does not imply a trade surplus.

Walnut, pistachio and hazelnut each have higher reported import values than export values. Almond has a $1,321.0m surplus.

Reading the chart

Teal circles show exports; brown diamonds show imports. A connecting line shows the monetary gap. The default view excludes almond to reveal smaller gaps. Check the box to include it. Missing endpoints are identified in each row, never positioned at zero.

Source: Hort Innovation, Australian Horticulture Statistics Handbook 2024–25. Source details

Data & methodology

Balance = reported export value − reported import value, in nominal A$ million. It is a monetary trade balance, not a physical production or consumption share.

Macadamia and pecan remain visible with reported exports of $246.6m and $2.5m. Their import values are printed as “–”; chestnut’s export value is “–” and its import value is reported as <$0.1m. The bounded import value is shown in text rather than plotted as an exact point. Here, “–” means no numeric value reported, not a confirmed zero. Pecan’s supply identity is consistent with zero import tonnage, but does not independently establish a published monetary import value. No balance is calculated for these incomplete pairs.
